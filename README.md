## Overview
A web application built with HTML, CSS and JavaScript to track and compare cryptocurrency and fiat currency prices using public APIs.

## Features
* Interactive price charts with drag and drop comparison
* Timeframe selection (24H, 7D, 30D, 90D, 1Y and 5Y)
* Custom line color selection
* Portfolio tracker with buy/sell recommendations
* Purchasing power table for crypto in EUR, GBP, JPY, CAD and CHF
* Instant currency converter
* Download charts as PNG or SVG

## Tools & APIs Used
* HTML5, CSS3 and JavaScript (ES6+)
* Chart.js
* Coinpaprika API
* Frankfurter API
* Binance API

## How to Run
Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari or Edge). No installation or build steps are required.
